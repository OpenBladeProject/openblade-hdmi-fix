# OpenBlade HDMI Fix

[English](README.md) | [简体中文](README.zh-CN.md) | Русский

Примените обходное решение для HDMI к сохранённому подключению монитора на Razer Blade.
Приложение показывает мониторы, которые запомнила Windows, поэтому проблемное
подключение можно исправить, пока монитор отключён от ноутбука.

Функция Patch снижает заявленные монитором максимальные скорости соединения HDMI с
FRL10 до FRL8 и сохраняет DSC включённым. Перед изменением она сохраняет исходное
состояние для функции Restore.

<a id="requirements"></a>
## Требования

- 64-разрядная Windows 11 на Razer Blade.
- Ранее подключённый HDMI-монитор, полные данные о возможностях которого сохранены в Windows.

Перед включением кнопки Patch приложение проверяет сохранённые поля HDMI и DSC
независимо от производителя и модели монитора. Оно предупреждает, что обходное решение
не проверялось на выбранном мониторе.

<a id="use-the-app"></a>
## Использование приложения

1. Не подключайте проблемный монитор к ноутбуку.
2. Скачайте ZIP для Windows со страницы
   [Releases](https://github.com/OpenBladeProject/openblade-hdmi-fix/releases),
   распакуйте его и откройте **OpenBlade.HdmiFix.exe** в папке `publish`. Запустите файл
   обычным способом.
3. Выберите сохранённое подключение монитора и проверьте предлагаемое изменение.
   Отдельные записи подключений показываются как отдельные элементы.
4. Выберите **Patch**, подтвердите запрос прав администратора и дождитесь подтверждения.
5. Снова подключите монитор и проверьте разрешение, частоту обновления, HDR, VRR и звук.

Изменяется только выбранное подключение. После смены порта, адаптера или драйвера Windows
может создать другую запись. Если проблема сохраняется, отключите монитор от ноутбука и
снова проверьте его сохранённые записи. При отсутствии совместимых сохранённых данных
кнопка Patch недоступна.

<a id="restore-and-backups"></a>
## Восстановление и резервные копии

Отключите монитор от ноутбука и откройте приложение под учётной записью Windows, которая
создала резервную копию. Выберите то же сохранённое подключение и нажмите **Restore**.
Дождитесь подтверждения, прежде чем снова подключать монитор.

Резервные копии остаются в `%ProgramData%\OpenBlade.HdmiFix.Backups` при замене папки
приложения. Храните их, пока не закончите пользоваться обходным решением. Раздел
**Backups and diagnostics** открывает папку или копирует отчёт без необработанных данных
EDID, серийных номеров, идентификаторов экземпляров устройств и локальных путей.

Чтобы исследовать повторяющееся пропадание изображения, выберите проблемное сохранённое
подключение и нажмите **Record connection** до подключения монитора. Нажимайте
**Mark blackout** при каждом пропадании изображения; запись остановится через 60 секунд.
Откройте папку записи и передайте файл `connection-recording.zip`. Отдельный журнал
дисплеев Windows может содержать конфиденциальные системные данные.
